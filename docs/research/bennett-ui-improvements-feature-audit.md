## Why the first color rewrite failed

The first rewrite depended entirely on `api.react.host.query("projects")`. The live overflow click in the supplied screenshot can occur while that semantic match set is empty or while the target button is represented only by the donor’s row markers. No project context meant the portal observer never started, despite the tweak being installed and loaded.

The corrected design preserves the semantic query as the primary route, then accepts only the verified live row shape. It resolves duplicate names by project path/ID first and selects only a visible `data-state="open"` project menu nearest the click. This retains the donor’s resilience while avoiding its timer polling, global color cache, and separate ownership namespace.
