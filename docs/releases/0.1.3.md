# Tweaker 0.1.3

Tweaker 0.1.3 is an auto-update and maintenance release. It makes Tweaker refresh itself hourly, improves the Codex update repair flow, and trims local logs so long-running installs stay tidy.

## Highlights

- Added hourly Tweaker self-update checks through the watcher.
- Added automatic Tweaker runtime download/build/repair when a newer Tweaker release is available.
- Added restart prompts when Codex is already open and needs to reload a freshly updated Tweaker runtime.
- Made Codex update repair alerts faster and clearer, including Codex-branded restart prompts on macOS.
- Added visible Codex update mode status so users can see when Tweaker is paused for the official Codex updater.
- Added Codex beta app metadata support for watcher health checks and repair state.
- Capped Tweaker runtime, loader, and watcher logs at 10 MB.
- Added GitHub issue links to unexpected CLI failure output.
- Fixed negated installer flags such as `--no-default-tweaks`.
- Fixed Homebrew install instructions.
- Removed bundled example tweak sources from the Tweaker release package. Default tweaks now come from their own release channels.

## Important Upgrade Note

Users already on 0.1.2 should run the bootstrap installer once to move onto 0.1.3:

```sh
curl -fsSL https://raw.githubusercontent.com/b-nnett/tweaker/main/install.sh | bash
```

Homebrew users can update with:

```sh
brew update
brew upgrade tweaker
tweaker install
```

After 0.1.3 is installed, Tweaker can check for future Tweaker releases hourly and prompt to restart Codex when a downloaded runtime update needs to be applied.

## For Users

When Codex itself updates, Tweaker now waits briefly, checks the app state, and repairs the patch automatically when possible. If Codex is already open and still running older app code, Tweaker prompts before quitting and reopening it.

The Tweaker Config page now shows clearer installed-version copy, Markdown-rendered latest release notes, watcher health, and update-mode state.

## For Tweak Authors

Example tweaks are no longer bundled in the Tweaker source release. Use the dedicated tweak repositories and release channels for Bennett UI Improvements and Custom Keyboard Shortcuts.

The installer still seeds default tweaks on install unless `--no-default-tweaks` is passed.

## Fixed

- Fixed updater and watcher scheduling so future Tweaker releases are checked hourly.
- Fixed the repair flow to avoid unnecessary re-signing when the patch is already intact.
- Fixed Codex beta metadata detection so beta installs report watcher health correctly.
- Fixed CLI error output so unexpected failures include a prefilled GitHub issue link.
- Fixed log growth by keeping known Tweaker logs at or below 10 MB.
