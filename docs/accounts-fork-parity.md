## Reference and attribution

The behavioral/UI reference is [braindead-dev/codex-subscription-router](https://github.com/braindead-dev/codex-subscription-router/tree/a1d3e02f1abfc5c077607a5ac08a5936530941a3), pinned at `a1d3e02f1abfc5c077607a5ac08a5936530941a3`. ## Desktop launch and conflict handling

- `tweaker launch-tweakers` and `tweaker launch-official` run the fixed sealed-manager handoff before opening the selected app. Ordinary Tweakers Dock/Finder launch uses the native wrapper before Electron starts.
- Directly opening the unmodified official app through Finder cannot be intercepted. Use `launch-official` to synchronize portable state in that direction.
- A running endpoint postpones the merge and permits launch without a coexistence warning. Divergent settings remain in their original homes. The managed command reports the conflicting fields; the Tweakers wrapper offers to open for review with synchronization postponed. Make the conflicting settings agree before the next handoff.
- The current official and derived main bundles match the inspected desktop state contract after narrowly normalizing generated import/source-map names and the exact Tweakers window-service capture. Other executable changes remain unsupported until reviewed.
- The primary-home read-only bootstrap preview found 76 available plugin packages and 143 capability files. Existing unavailable plugin references and dangling local Skill links remain local; their missing targets are never fabricated.
